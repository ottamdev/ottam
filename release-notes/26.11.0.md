The first release of Ottam, a native Mac app for running coding agents. It is
an early release, so expect rough edges.

- Chat with Claude Code, Codex, OpenCode and oh-my-pi in one workspace.
  Conversations survive restarts, and you can switch agents mid-conversation.
- Approve tools and answer agent questions right above the composer, and
  review an agent's plan before it starts.
- Review the diff, open files and run terminals beside the conversation.
- Agents can hand tasks to each other. Each one becomes its own conversation,
  nested under the one that started it.
- Add an MCP server once in Settings, and every agent can use it.
- Ottam installs each agent for you, along with Node if you need it.
- Ottam updates itself. When an update is ready, a button appears at the
  bottom of the sidebar.

Requires macOS 26 on Apple silicon.
