# Agent Efficiency: Refactors And Tooling For Agent-Maintained Code

## Current Status

Open work makes the repository cheaper for coding agents to read, edit, and
verify: mechanical file splits, generated-artifact markers, a shorter
`AGENTS.md` with leaf guides, and reviewer-visible UI evidence. P0-8, P0-12,
P1-5, and P2-7 are partial; nothing else has landed. P1 splits and P2 cleanup live in
[File Splits And Cleanup](agent-efficiency-splits.md). Next: the mechanical
block at the top of [Order](#order). Re-measure after that block lands.

## Findings That Drive The Plan

Measured 2026-09-04 over ~300 Claude and ~480 Codex transcripts.

- **Cost is prompt size × request count.** About 65 % of cost-weighted tokens
  are cache reads and a block stays resident for ~50 later requests. Resident
  instruction text (`AGENTS.md`) is paid on every request. File splits are
  justified by friction, not token share: paged reads of god-files, truncated
  searches, ambiguous Edit anchors, retry loops.
- **Agents page the same large files.** `sed`/`nl`/`cat` paging was half of
  Codex shell output. The hot files are the chat workspace view and model, the
  transcript view, `agent/registry.rs`, `agent/model_catalog.rs`, the
  transcript coordinator, and the agent test files. These files also have the
  most commits. Overloads and forwarders that repeat a name make Edit anchors
  ambiguous.
- **Generated protocol artifacts look hand-editable.** `tests/artifacts.rs`
  byte-guards them, so a hand edit reverts with a confusing failure.
- **Screenshots cost wall-clock time more than tokens.** A full 2200 px frame
  costs ~1,500–2,150 tokens; a 600×400 crop costs ~320. `ui-test.sh run` blocks
  for 25 s median and 107 s p90.
- **Published guidance.** Keep the root instruction file
  short (Anthropic: under 200 lines; `@imports` do not reduce context cost).
  Claude Code, Codex (32 KiB chain cap), Cursor, and Copilot all apply the
  nearest `AGENTS.md`. Keep files readable in one `Read` (25 k-token cap) with
  unique anchors. Keep repository overviews on demand: an ETH/LogicStar study
  (arXiv 2602.11988) found that resident overviews did not help and raised cost
  by ~20 %.

## Backlog

- **Shell guard hook (deferred).** This covers command/read deny rules,
  repeated-failure tracking, and a `scripts/search.sh` wrapper. Revisit only if
  measurements show persistent search/read or retry friction that guidance has
  not fixed. If it is revisited, pilot advisory feedback before blocking rules.
- **Architecture findings with no read-pressure case.** Promote one only when a
  task opens in its area:
  - `Database` carries payload coordination → a `PayloadLeases` type.
  - Tests run different timing constants than production
    (`#[cfg(not(test))]` pairs) → injectable `Timings`.
  - Stringly errors (`CoreError.kind: &'static str`, `Result<_, String>`) and
    repeated `lock().unwrap_or_else(|p| p.into_inner())` → enum kinds and a
    `lock_or_recover` helper.
  - `#[cfg(test)] pub(super)` accessors in production files.
  - `storage/runtime_store.rs` imports protocol types.
  - `@unchecked Sendable` in `OttamBackendClient`.
- **UI surfaces with no registered scenario.** These include:
  - Review/diff pane content, composer attachments, Settings typography and
    Terminal interactions.
  - Sidebar context menus and archive confirmation, window restoration,
    terminal input/replay, and the chooser happy path.
  - Sign-in with a real CLI, install progress, menus and toolbar, the Quit
    waiting panel, and recovery/attachment hosted cards.

  Add scenarios when a milestone touches one, for example
  `settings.app-typography`, `chat.attachments`, `chat.runtime-recovery`, or
  `window.title-and-menus`.
- **`ui-test.sh diff <archive-a> <archive-b>`.** Strip frames and timestamps
  with `jq`, then `diff -u` per captureID. This gives AX regression evidence
  without pixels.
- **`scripts/orient.sh <area>`.** A compact symbol index for the hot files.
  Most post-compaction file access re-reads the same six files. Do it after the
  P1 splits, and keep it a script, not resident text.
- **`scripts/doc-outline.sh <file>`.** Prints the heading tree with line ranges
  and word counts. The `track` skill would then read the outline plus the
  target section.
- **`OttamTranscriptUI` target.** Revisit only if incremental build time
  becomes the bottleneck. It needs `ChatWorkspaceModel` coupling untangled
  first.

## Decisions

- 2026-09-04: Rank interventions by measured share of the bill or measured
  friction, not anecdote. No session-shape, batching, or preamble work is in
  the active plan.
- 2026-09-04: Defer the shell guard hook. Guidance and existing tools come
  first.
- 2026-09-04: `AGENTS.md` is the source of truth for agent guidance;
  `CLAUDE.md` only imports it. Guidance must travel with the repository.
- 2026-09-04: Do not move `backend/target` out of tree via
  `.cargo/config.toml`, because it breaks hardcoded call sites. A personal
  `CARGO_TARGET_DIR` is fine.
- 2026-09-04: Do not deny `Read(/references/**)` or `Read(/.build/**)`. The
  first is read legitimately, and the second would block the crop directory.
- 2026-09-04: Do not split `ProtocolTypes.generated.swift`, because it is
  rarely read. Generating `ProtocolMethod` (P1-14) adds output; it is not a
  split.
- 2026-09-04: Leave the live `check-*.sh` guards in `test-rust-core.sh`,
  because they are cheap. P2-2 consolidates their helper and audits the
  one-shot migration guards.
- 2026-09-04: Leave `Package.swift` targets as they are. Keep
  `docs/operations/performance/*` separate from `markdown-renderer.md`.
- 2026-10-13: Do the mechanical block before any behavior-adjacent split; each
  pays off in every later session.
- 2026-10-13: Split data from logic in `registry.rs` and `model_catalog.rs`
  (P1-12). The definitions grew, and the catalog is an undocumented on-disk
  format. `auth.rs` stays.
- 2026-10-13: Promote the two Rust agent test-file splits to P1-15 on churn.
  The other test-file splits stay in P2.
- Open: delete the `OttamCoreProcessClient` forwarders (P1-6 with P1-9)? It is
